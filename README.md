# Maya UE 碎 UV 修复 · 1.0.2

用于 UE 静态网格导入 Maya 后，相邻三角形的 UV 坐标仍在原位，但被拆成许多独立 UV 壳的情况。工具在所选模型的副本上处理当前 UV 集。

## 在 Maya 2025 中使用

1. 解压 ZIP，把 UEUVRepair_102.py 从文件夹直接拖进 Maya 视口，确认窗口标题为 1.0.2。
2. 在 UV 编辑器切换到需要修复的 UV 集，回到物体模式，选中原模型。点击「检测选中模型」。
3. 默认 UV 容差为 0。日志显示可缝边时，点击「生成修复副本」。如果日志显示可焊顶点，并已确认它们属于同一零件，可勾选「同时修复断开的几何顶点」后再生成。
4. 选中生成的 _UVfix 副本，在模型视口按 Ctrl+1 隔离显示。在 UV 编辑器用「UV 壳」点选原先碎开的面，核对贴图、壳数量及着色。

## 参数与边界

- 默认要求对应边的两个 UV 端点坐标完全重合，并保留材质分界。只存在微小坐标偏差时，可从 0.000001 的 UV 容差开始，在原模型上重新检测。
- 两片 UV 已经重新排开时，工具无法推回原始布局。有意剪开而又完全重合的接缝可能被缝回。关闭几何焊接可避免误连相邻独立零件。
- 几何焊接默认关闭。启用后请检查硬边、法线和材质外观。
- 1.0.2 可直接拖放启动，避免旧菜单调用旧版。若仍遇到 math.dist 报错，核对窗口标题和日志首行的版本、文件名，再查看日志中的报错行号。

## 验证范围

修复逻辑已在模拟网格上检查。Maya 2025 中的实际资产修复效果请以副本检查结果为准。
